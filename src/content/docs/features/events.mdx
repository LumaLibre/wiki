On LumaMC, we hold periodic events where you can take part in limited time minigames and earn event currency to buy special prizes.
Use `/event` to check for an active event and to travel to the event area!
Our event areas and minigames are built from the ground up by our dedicated team of developers!

## Common Commands

<div class="list">

    - `/Event` - Teleports you to the active Event area.
    - `/Event Next`  - Checks for upcoming Event-related Minigames.
    - `/Event Join` - Joins the active Event Minigame.
    - `/Event Quit` - Removes you from an active Event Minigame.
